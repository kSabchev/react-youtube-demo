# YouTube Clone

A small React video-browsing interface built with Vite, Material UI, and React Router.

## Requirements

- Node.js 22.12 or later
- npm

## Available scripts

Run these commands from the `youtube-clone` directory:

### `npm install`

Installs the project dependencies.

### `npm start`

Starts the Vite development server. Open the local URL printed in the terminal.

### `npm test`

Runs the test suite once with Vitest.

### `npm run build`

Creates a production build in the `dist` directory.
